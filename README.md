# ⚡ TECNOLOGY S.A.S
### Tienda virtual de productos tecnológicos con diseño tecnológico

## 🚀 Tecnologías usadas
- HTML5
- CSS3
- JavaScript
- MySQL / XAMPP

## 📋 Páginas del proyecto
| Archivo | Descripción |
|---|---|
| `TECNOLOGY.html` | Página de inicio |
| `productos.html` | Catálogo de productos |
| `servicios.html` | Servicios |
| `contactos.html` | Contacto |
| `Dashboard.html` | Panel principal |

## ✨ Funcionalidades
- Carrito de compras con localStorage
- Sistema de login con autenticación
- Filtros por categoría y buscador
- Tarjeta de pago simulada
- Diseño responsive
